# === Notes on hardware ===
# - "Colab A100-SXM4-80GB" is Colab Pro+ A100 (80 GB VRAM); used for all 7-standard-model runs.
# - "Colab G4_GPU-96GB (RTX PRO 6000 Blackwell Server Edition)" is the new Colab "G4" runtime
# (95.0 GB VRAM); used for all Llama-70B-4bit runs starting 2026-04-22 because the
# bf16 KV cache for 80 layers × 64 heads requires the larger VRAM.
# - "causal-importance reanalysis (v2)" used an A100-80GB for 7 standard models (1 of the runs got
# an A100-40GB instead — see `models/{m}/causal_importance_reanalysis_v2_session_consistent/config.json`
# field `_session_log` for the exact GPU per run); 70B got the G4 95GB.
# - "novelword paper-Main canonical update" (04-29~30) re-ran the Phase A/B/C/D/E pipeline for 4
# models (Llama-3.1-8B-Instruct, Gemma-2-9B-IT, Gemma-3-27B, Llama-3.1-70B-Instruct-4bit)
# to apply the equal-k convention used throughout the paper and to guarantee
# session-consistent transformers pinning (Cell 1 explicit `==5.0.0` for the 3 7-standard
# models, `==5.6.0` for 70B). The other 4 models (Qwen-7B, Qwen-14B, OLMo-13B, GPT-J-6B)
# were not re-executed because their Apr 21 outputs are byte-equal under the same env.
# - "causal-importance reanalysis (v3)" (04-30) executed the C'/D' (causal-importance axis) group
# patching using the canonical paper-Main `30_patching/individual_head_effects.csv` as the
# per-head causal-imp source (median split over the same 4 canonically updated models + Qwen-7B
# + Qwen-14B; OLMo + GPT-J use the v2 reanalysis as canonical since the main pipeline is unchanged
# for those models). This is purely a re-classification + re-patching pass — no Novel Word data collected.
# - The Colab notebook `unified_pipeline_v7_5_0.ipynb` and 7 model-specific variants
# produced the paper-Main 7-standard runs; `unified_pipeline_llama70b-4bit_v7_5_0.ipynb`
# produced 70B paper-Main.
# - Prospect notebooks: `prospect_v7_5_5_*.ipynb` (8 model-specific variants).
# Each notebook produces deterministic output given the pinned environment block and
# the WORD_SEED=2027 stimulus seed.

# === Notes on transformers version ===
# Three distinct transformers versions across the runs:
# - **5.0.0** — Colab default at 2026-04-13 ~ 04-22. Used by:
# ACDC-cross-model (04-13, but TransformerLens path),
# FactRec 7-standard (04-18~19, `pip install transformers` no-U → no upgrade),
# paper-Main 7-standard (04-21, no explicit transformers install),
# Prospect 7-standard (04-22, `pip install transformers` no-U → no upgrade),
# paper-Main 7-standard canonical update (04-29~30, Cell 1 EXPLICITLY pinned `==5.0.0`
# to neutralize Colab default drift; matches Apr 21 origin).
# - **5.6.0** — Released 2026-04-22T15:41Z. Pulled by `pip install -U transformers` in:
# paper-Main 70B (04-22, install line uses `-U`),
# Prospect 70B (04-23, Cell 1 explicitly logs "Uninstalling transformers-5.0.0... Successfully installed transformers-5.6.0"),
# paper-Main 70B canonical update (04-29, Cell 1 EXPLICITLY pinned `==5.6.0` for
# session-consistency; matches Apr 22 origin).
# - **5.6.2** — Released 2026-04-23T18:33Z (latest at run date). Pulled by `pip install -U transformers` in:
# FactRec 70B (04-25, install line uses `-U`),
# causal-importance reanalysis (v2) (04-26~27, install line uses `-U`),
# causal-importance reanalysis (v3) (04-30, install line uses `-U`; PyPI confirms
